# 🌍 Blaze Tours Booking Platform

A modern tourism and travel booking platform developed for **Blaze Tours (Pvt) Ltd**, designed to showcase Sri Lankan travel experiences and simplify the tour booking process through an intuitive and responsive user interface.

## 🚀 Features

### User Features

* Browse available tour packages
* View detailed tour information
* Tour image galleries
* Secure online booking process
* Payment integration
* Contact and inquiry system
* Mobile-friendly responsive design
* SEO-optimized pages

### Admin Features

* Tour management
* Booking management
* Customer inquiry management
* Tour location updates
* Content management
* Dashboard administration

## 🛠️ Technologies Used

### Frontend

* HTML5
* CSS3
* JavaScript
* SCSS

### Backend

* PHP

### Database

* MySQL

### Additional Tools

* PHPMailer
* OAuth Integration
* Payment Gateway Integration

## 🎯 Project Objectives

The goal of this project was to create a modern digital platform for a tourism company, enabling customers to easily discover and book Sri Lankan travel experiences while providing administrators with efficient management tools.
